====  Introduction

You can use TestMu AI (Formerly LambdaTest) as a robot infrastructure.

https://www.testmuai.com/[image:lambdatest-logo.png[TestMu AI,200,100]]

TestMu AI advanced integration covers: 

* An automatic mapping of capabilities (test name, tag/build values, verbose execution level,... ). Parameter `cerberus_lambdatest_defaultexename` can be used in order to tune the name of the execution on the TestMu AI side (default to `Exe : %EXEID% - %TESTDESCRIPTION%	`).

* Automatic update of execution status

* Easy access from Cerberus to TestMu AI execution from the `robot` tab or `go to` menu.

====  Create/Update the Robot

To execute the tests with TestMu AI the robot executor must be added/updated with the following values:

* *Hostname* - `hub.lambdatest.com` (TestMu AI still uses this hostname)
* *Host Username* - `lambdatest_username`
* *Host Password* - `lambdatest_access_key`

image::lambdatestrobot.png[Robot Configuration]
